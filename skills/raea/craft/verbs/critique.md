# critique

Judge the piece as it rendered, not as you meant it, before you call it done or when the person asks "is it good?".

## How
- Watch the export once, all the way through, at the size it ships, with sound. Then pull stills at the moments that
  matter and look at them together.
- Judge it against the brief (`believe:`, `audience:`), the person's taste, the mode's guide and the floor.
- Run `raea check` for what can be measured, and judge the rest by the rubric (`raea guide rubric`).

## Write it down
- Each issue: where (the part or the moment), what's wrong, and why it matters to the audience.
- Rank each one: P0 breaks the piece (a floor defect, a wrong fact), P1 the audience would notice, P2 makes it better,
  P3 polish.
- Name the strongest moment too, so polish doesn't sand it off.
- Post the critique as a test item, so the next pass and the person can see it.

## Then
- Fix P0 and P1 before showing anyone. `polish` works through the rest.
